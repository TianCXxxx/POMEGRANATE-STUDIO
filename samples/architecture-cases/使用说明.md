# 代码生成架构图 · 测试资料

这些示例用于测试架构关系，不是生产系统，也不需要运行源码。可在「代码项目」选择同名文件夹或 ZIP。前三组各约 40 个小文件，第四组为较小的中等规模案例，均远低于当前 1000 文件 / 20 MB 文本上限。

1. **订单交易平台**：前端 → 订单 → 库存、支付 → 数据库；RabbitMQ → 通知服务。
2. **仓储履约网络**：前端 → 履约 → 仓储、运力；RabbitMQ → 跟踪服务。
3. **企业指标分析平台**：前端 → 指标 → 身份、目录；Redis 缓存和 RabbitMQ → 报告服务。
4. **会议室预约系统（中等规模）**：前端 → API → 预约 / 会议室服务 → SQLite，另有内部通知模块。

预期关系分别记录在项目目录之外的 `预期关系.md` 中，导入源码时不包含答案。地址和连接串都是演示用占位信息；代码用于静态分析，不提供可直接部署的容器镜像。比较时重点查看前后端分层、调用方向、服务边界、端口、数据访问及消息订阅。动态依赖和间接调用可能需要人工核对。
